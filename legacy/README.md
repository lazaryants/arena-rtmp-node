# Legacy

Здесь сохранена отключённая историческая реализация DVR только как справочный материал. Она не устанавливается, не запускается и не считается частью поддерживаемой архитектуры.

Новая DVR-подсистема должна проектироваться отдельно: с ограничением диска, ротацией журналов, контролируемым retention и тестами восстановления после потери входного потока.
